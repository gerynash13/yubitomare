# detox_pet

**スマホを開く前に、ちいさな相棒とひと呼吸。**

detox_pet（デトックス・ペット）は、つい開いてしまうアプリとの付き合い方を見直し、やりたいことへ戻るきっかけをつくるスマートフォンアプリです。文鳥の相棒「とまりん」が、アプリ利用時の声かけ、集中時間の見守り、日々の振り返りを通してユーザーに寄り添います。

アプリの利用を一律に禁止するのではなく、「今どうするか」を自分で選ぶための小さな間をつくることを目指しています。利用時間の削減効果を実証したものではなく、現在は機能を開発・検証している段階です。

## できること

- **使いすぎに気づく** — 見守り対象に選んだアプリを開くと、とまりんが確認画面を表示します。戻る、一時的に使うなどの選択肢を通じて、無意識の操作をいったん止めます。
- **今日のタスクを決める** — やることを登録し、完了を記録できます。
- **集中する** — タスクや目標を選び、とまりんと一緒に集中します。セッション中の確認に応答した時間をもとに、集中時間を記録します。
- **取り組みを振り返る** — 集中後に進み具合やメモを記録し、Record画面で最近の記録や一週間の集中時間を確認できます。
- **自分に合わせる** — 見守り対象アプリ、呼び名、言語などを設定できます。アプリ内の表示言語は日本語と英語に対応しています。

## 画面の構成

| 画面 | 役割 |
| --- | --- |
| **Today** | 見守り状態、今日のタスク、とまりんとの絆を確認する |
| **Focus** | タスクや目標を選び、集中セッションを始める |
| **Record** | 最近のセッションと一週間の集中時間を振り返る |
| **設定** | 言語、呼び名、対象アプリ、通知までの時間などを設定する |

基本の流れは **設定 → 今日のタスク → 集中 → 振り返り** です。対象アプリを開いたときの確認画面は、この流れに戻るためのもう一つのきっかけです。

## デザインコンセプト

### 「あたたかい紙の上の、手書きの連絡帳」

画面全体を、やわらかな紙の色と手帳のモチーフでまとめています。厳しい制限アプリのような冷たさではなく、とまりんが隣で見守ってくれる親しみやすさを表現します。タスクカードや記録は、紙片を貼ったノートのように見せています。

- **ベースカラー** — 紙のようなアイボリー `#FFF8F6` と淡いピンク `#FFF1EC`
- **文字色** — あたたかみのある濃いブラウン `#261813`
- **アクセント** — 判子や注意を表す朱色 `#B41F09`、元気さを添える柿色 `#FFA944`
- **集中画面** — 周囲から切り替えるための夜色 `#3D2D27`
- **書体** — 見出しは Dela Gothic One、手書き風のアクセントは Yusei Magic、本文は Zen Maru Gothic
- **モチーフ** — とまりんの表情差分、吹き出し、マスキングテープ、紙カード、はんこ

### 表現のルール

1. **責めずに、選び直す余地を残す。** 失敗や未達成を罰するのではなく、小さな次の一歩を提案します。
2. **情報は紙片のように整理する。** カードや余白で区切り、1画面に詰め込みすぎないようにします。
3. **とまりんの表情で気持ちを伝える。** 強めの声かけもキャラクターの演出として見せ、画面全体の温度は保ちます。
4. **強調色は役割を持たせる。** 朱色は重要な行動や判子、柿色は前向きなアクションに使います。
5. **集中中は視覚的な刺激を減らす。** 暗い背景とシンプルな表示で、ホーム画面との切り替えを感じられるようにします。

### 発表スライドにも使うデザイン

- 背景はアイボリー、本文は濃いブラウンを基本にする。
- 朱色と柿色は、キーワードや図の矢印など少数のポイントに使う。
- 見出しは太く短くし、本文は一枚につき要点を一つに絞る。
- スクリーンショットやとまりんのイラストを主役にし、説明文を詰め込まない。
- 機能紹介は「気づく → 選ぶ → 集中する → 振り返る」の順で見せる。
- 紙カードやマスキングテープのモチーフを使い、アプリのノートらしい雰囲気にそろえる。
- 「使いすぎを防止する」と断定するより、「使い方を見直すきっかけをつくる」と表現する。

## 技術構成

- **Flutter / Dart** — アプリの画面、状態管理、ローカライズ
- **Androidネイティブ（Kotlin）** — 利用状況の検知、見守りサービス、確認画面の連携
- **SharedPreferences** — タスク、設定、絆、集中ログなどの端末内保存
- **Supabase Edge Functions と外部LLM API** — キャラクターの声かけや振り返りコメントの連携

見守り対象アプリの検知にはAndroidの利用状況アクセス権限が必要です。確認画面の表示にはオーバーレイ権限も使用します。そのため、アプリの利用状況を検知する機能は現在Android向けです。iOSなど他のプラットフォームで同じ見守り機能が使えることを示すものではありません。

AIを使った振り返りコメントでは、入力されたメモなどがサーバー経由で外部LLMに送信される場合があります。個人情報や送信したくない内容は入力しないでください。AI連携が利用できない場合に備え、アプリには固定コメントも用意されています。

## 開発状況と注意点

- 集中中の確認間隔は、現状のコードでは**テストモード**になっています。実運用向けの間隔や挙動として紹介する前に、設定と実機動作を確認してください。
- 見守り機能を使うには、初回設定で対象アプリを選び、Androidの必要な権限を許可する必要があります。
- アプリは開発中です。記録や画面の内容はバージョンにより変更されることがあります。

## 開発環境

- Flutter SDK（`pubspec.yaml` のDart SDK制約を満たすバージョン）
- Android StudioまたはAndroid SDK（Androidで実行する場合）
- iOS向けのビルドにはmacOSとXcodeが必要です。なお、見守り機能はAndroidネイティブ実装です。

## セットアップ

```bash
flutter pub get
flutter run
```

Android端末またはエミュレーターで見守り機能を試す場合は、アプリ内の初回設定で対象アプリを選択し、利用状況アクセスとオーバーレイの権限を許可してください。
